# GLAMBIE Capstone Project

Repository for the Reanalysis "Community estimate of global glacier mass changes from 2000 to 2023" published by Zemp at al. (2025) for the "Capstone Project" module.

## Structure

- Comment.pdf - two page comment
- Reanalysis.pdf - detailed description of our renanalysis (also as html and ipynb)

Inside the capstone_glambie folder:

- **input/** – glambie original results, modified runs in regular and in adjusted format (glambie_runs_clean), input datasets and initial glacier mass data (based on Zemp et al., 2025)
- **output/** – generated plots of input datasets by inclusion/exclusion, barcharts of variation of estimates due to dataset inclusion/exclusion
- **glambie/** – files containing functions from the glambie model we cite in our analysis
- **scripts/** – additional notebooks for analysis and plotting
- **help_functions/** – helper functions for plotting
